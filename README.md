# Testing-site

ShopMate is a small static storefront built with HTML and CSS.

## Files

- `Shop Mate site/index.html` - storefront and selectable cart
- `Shop Mate site/checkout.html` - checkout demo page
- `Shop Mate site/styles.css` - shared styles
- `Shop Mate site/images/` - product photos

## Run locally

Open `Shop Mate site/index.html` in a browser, or serve the `Shop Mate site` folder as the site root. No build tools or dependencies are required.

The cart and checkout are a front-end demo. Selected cart items do not persist across pages, and orders are not processed.
