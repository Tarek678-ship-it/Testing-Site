# Testing-site

ShopMate is a small static storefront built with HTML and CSS.

## Files

- `index.html` - storefront and selectable cart
- `checkout.html` - checkout demo page
- `css/styles.css` - shared styles
- `assets/images/` - product photos

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

The cart and checkout are a front-end demo. Selected cart items do not persist across pages, and orders are not processed.
